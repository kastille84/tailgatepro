# Original-talk authoring: proposed selection (option 2)

**Outcome:** 20 of the 29 proposed talks were written and approved. 125, 161, 251, 256, 156, 163 were dropped because no readable source supported them (blocked page, or the rule found does not cover the topic); 089 and 097 for source reuse/overlap; 071 was merged into 066 and 077 into 078 (Winter Driving). Titles changed to match sources: 062 Overhead Hoists, 111 Flammable Liquid Storage, 133 Sanitation and Hygiene on the Jobsite, 170 Debris and Waste Disposal, 172 Hazardous Waste on the Jobsite, 278 Working Over or Near Water, 078 Winter Driving, 159 Working in Occupied Buildings.

Scope decision: write original talks for the construction-relevant part of the 146 unsourced Word-library talks (`needs_revision`), **with no topic overlap with the 92 approved talks**. Each talk is written from a fetched OSHA/NIOSH rule or guidance page, with only verified citations, then audited. Nothing is written or seeded until this list is confirmed.

Result of the overlap screen: **29 talks proposed**, 117 dropped. The count is lower than the ~70 first estimated because the approved library already covers most of the core topics (fall protection, rigging, chemicals/SDS, confined spaces, driving, JHA, leadership, housekeeping). "Borderline" means an approved talk touches the topic in a bullet or two; the new talk would be a dedicated deep-dive, and I will drop it if it turns out to repeat that talk.
